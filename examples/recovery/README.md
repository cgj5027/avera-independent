# Encrypted household example

`avera-established-household-two-properties.avera` contains synthetic data for an
established household with a primary residence and a rental property. It includes
495 records: 419 transactions, eight accounts, four income sources, two properties,
two linked mortgages, budgets, bills and savings goals. No personal records or
provider credentials are included.

The recovery passphrase is provided separately and is not stored in this repository.
Download the file using GitHub's **Raw / Download raw file** action, then open Avera's
**Settings → Backup and recovery → Review or restore a backup**. Choose the file,
enter the separately supplied passphrase and review the preview.

Use a dedicated test account. Applying a restore replaces the destination account's
financial records; downloading or previewing does not apply the restore.
